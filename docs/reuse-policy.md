## העיקרון

> **המטרה היא התוכנה הכי טובה שאפשר לבנות — לא כמה קוד מקורי כתבנו.**

SongVoice נשארת מוצר וארכיטקטורה עצמאיים. אבל כשקיים מימוש בוגר ומוכח למשהו
שאנחנו צריכים — **משתמשים בו**, לא כותבים אותו מחדש.

שני הכיוונים אסורים באותה מידה:

| ❌ לא עושים | ❌ וגם לא עושים |
|-------------|------------------|
| לשכתב קוד בוגר שעובד רק כדי שיהיה "שלנו" | להעתיק אפליקציה שלמה |
| להמציא מחדש inference של RVC | לרשת ארכיטקטורה, ממשק, תלויות וחוב טכני מיותרים |

## סולם ההחלטה

לפני מימוש של כל רכיב מנוע משמעותי — **קודם בודקים אם כבר קיים מימוש בוגר**.
ואז בוחרים אחת מחמש:

```
1. שימוש ישיר        ← החבילה קיימת ב-pip, מתוחזקת, ומתאימה כמו שהיא
2. התאמה             ← כמעט מתאים; משנים מעט
3. עטיפה במתאם שלנו  ← מצוין כמו שהוא, רק צריך להתאים לממשק שלנו
4. הכנסת תת-קבוצה    ← לוקחים קבצים ספציפיים לתוך הריפו, מנוקים
5. מימוש עצמי        ← רק כשאף אחת מהאפשרויות למעלה לא טובה מספיק
```

**קריטריוני הבחירה, לפי סדר:**

1. איכות שמע
2. אמינות בעולם האמיתי
3. תאימות רישוי
4. יכולת תחזוקה
5. תאימות ל-Windows
6. תמיכה ב-CUDA
7. תמיכה ב-Intel Arc / Core Ultra
8. גיבוי CPU
9. כיסוי בדיקות
10. איכות האינטגרציה עם SongVoice

## מה נשאר ייחודי ל-SongVoice

אלה **לב המוצר**. הם לא מוחלפים בקוד מאף מקור חיצוני:

- ניתוח אוטומטי של מנעד השירה במקור
- ניתוח פרופיל ומנעד של קול היעד
- מדידת `quality_vs_shift` לכל קול
- אסטרטגיית הגובה והמנעד האוטומטית
- **מנוע ההחלטה `s = 12k + r`**
- אסטרטגיית התאמת הפלייבק
- הבחירה האוטומטית בין הזזת מיקס שלם לבין פיצול לשכבות
- בחירת מסלול החישוב האוטומטית **לכל שלב בנפרד**
- הזרימה הפשוטה: שיר ← קול ← התחל
- אפליקציית PySide6 נטיבית
- חוויית משתמש מלאה בעברית ו-RTL
- פרויקטים, cache, התאוששות וניהול משימות
- Preview אוטומטי והמלצה
- מערכת הבנצ'מרק וההאזנה העיוורת

## אימון קול (Phase 9)

**לא ממציאים מערכת אימון חדשה.**

ב-Phase 9 נבדוק את מימוש האימון הבוגר ב-Applio וב-RVC-Project, ונשתמש בחזק מביניהם
מאחורי `TrainingBackend` נקי משלנו.

מה שכן שלנו — **האשף**:

```
הוסף הקלטות → בדיקת איכות → ניקוי אוטומטי → הכנת דאטהסט
    → אימון → בניית index → פרופיל הקול → הקול מוכן
```

המשתמש לא אמור לדעת מה זה epoch, feature extraction, index או preprocessing —
אלא אם הפעיל מצב מתקדם.
