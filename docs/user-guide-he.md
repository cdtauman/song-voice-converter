# מדריך משתמש — SongVoice 1.0

SongVoice היא תוכנת Windows מקומית ליצירת קאבר בקול יעד מורשה. השמע והקולות
נשארים במחשב; נדרש אינטרנט רק להורדת מודלים ולעדכוני תוכנה.

למדריך חזותי קצר: [סרטון quick-start עברי (ללא קול, כ־50 שניות)](media/songvoice-quickstart-he.mp4).

## התקנה והפעלה ראשונה

1. הפעל את `SongVoice-1.0.1-Setup.exe`. להתקנה ללא אינטרנט השתמש ב־
   `SongVoice-1.0.1-Offline-Setup.exe`.
   אם מתקין ה־offline מופיע ב־GitHub כקבצי `part001`, `part002` וכדומה,
   הורד את כל החלקים לאותה תיקייה, הרכב אותם, ורק אז הפעל את המתקין:
   `powershell -ExecutionPolicy Bypass -File .\Join-SongVoice-Offline-Installer.ps1 -FirstPart .\SongVoice-1.0.1-Offline-Setup.exe.part001`.
2. אשף ההפעלה הראשונה בודק את המעבד/כרטיס המסך, את ffmpeg ואת מודלי הליבה.
3. בהתקנה המקוונת השאר את החיבור פעיל עד שהמודלים מסומנים כתקינים. אם החיבור
   נקטע, הפעל שוב לאחר שחזר — ההורדה ממשיכה מהקובץ החלקי.

אין צורך להתקין Python או CUDA. ניתן להסיר את התוכנה דרך הגדרות Windows; ההסרה
מוחקת גם את נתוני SongVoice המקומיים, לכן ייצא קולות שברצונך לשמור לפני כן.

## קאבר ראשון

1. פתח **ספריית קולות**. הוסף קול קיים או הפעל את אשף האימון. אשר את הצהרת
   ההרשאה רק לקול שיצרת בעצמך או שיש לך רשות מפורשת להשתמש בו.
2. עבור אל **קאבר חדש** ובחר WAV, MP3, M4A, FLAC או OGG.
3. בחר קול יעד ורמת איכות. התחל ב־**מאוזן**.
4. צור Preview, האזן להשוואה ובדוק שהמילים והמנגינה ברורות.
5. אשר את ההמלצה וצור את השיר המלא. הקובץ נשמר ליד המקור בשם שמסתיים
   ב־`SongVoice.wav`; קובץ קיים אינו נדרס.

## קולות ואימון

- חומר אימון מומלץ: 15–30 דקות של קול יחיד, ללא מוזיקת רקע חזקה וללא clipping.
- אפשר לעצור ולהמשיך אימון. סגירה או קריסה אינן מוחקות שלבים שכבר פורסמו בהצלחה.
- כרטיס קול שאינו תקין מציג פעולה מוצעת. אל תעתיק ידנית קובצי model/index בין
  תיקיות; השתמש בייבוא ובייצוא של הספרייה.

## מצב מתקדם ומעבדת השוואה

מצב מתקדם מיועד להשוואה מבוקרת של tuning, מרחב אקוסטי והגדרות המרה. לפני שינוי
ברירת מחדל, צור Preview והשתמש בנגן A/B העיוור. מדד מספרי אינו מחליף האזנה.
מנועי benchmark חיצוניים תחת `env-bench` אינם חלק מהמוצר המותקן.

## המשך לאחר עצירה

בפתיחה הבאה SongVoice מציעה להמשיך קאבר שנעצר. שלבים שהושלמו נקראים מהמטמון,
והשלב שנקטע רץ מחדש. הורדת מודל שנקטעה נשמרת כ־`.part` וממשיכה באמצעות HTTP Range.
אפשר לבטל פעולה פעילה; קובצי scratch ופלט חלקי אינם מחליפים תוצאה תקינה.

## פתרון תקלות

| הודעה | מה לעשות |
|---|---|
| לא הצלחנו לפתוח את קובץ השמע | נסה MP3, WAV או M4A תקין. |
| לא זיהינו שירה | נסה מיקס שבו השירה ברורה, או קובץ אחר. |
| אין מספיק מקום בדיסק | פנה מקום והפעל שוב; הורדה/פלט חלקיים מנוקים בבטחה. |
| ההורדה נכשלה | בדוק חיבור ולחץ שוב; החלק שכבר ירד נשמר, אלא אם היה פגום. |
| חסר רכיב עיבוד שמע | התקן מחדש מהמתקין המאומת. |
| נגמר זיכרון כרטיס המסך | המנוע מוריד אוטומטית את גודל העבודה; אם הכשל חוזר, נסה איכות מאוזנת. |

המסך **עזרה** בתוך התוכנה כולל את הפעולות החשובות גם ללא אינטרנט. לאבחון טכני
אפשר להריץ `svc doctor --json`; הדוח מקומי ואינו מעלה שמע.

## עדכונים, פרטיות והרשאה

עדכון מורד ב־HTTPS, נבדק לפי גודל ו־SHA-256, ומותקן בהפעלה הבאה עם rollback במקרה
כשל. אין לעקוף אזהרת checksum. SongVoice אינה מעלה שירים או קולות לענן. הורדות
מודלים ועדכונים הן תעבורת הרשת היחידה של מסלול השימוש הרגיל.

האחריות להשתמש בקול מורשה היא של המשתמש. אין להשתמש בקול של אדם אחר ללא הסכמה
מפורשת, ואין לשתף מודל או פלט בניגוד לרישיון חומר המקור.
