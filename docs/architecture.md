# ארכיטקטורה ותכנון UX

---

## 1. עקרונות היסוד

1. **הפרדה מוחלטת בין מנוע לממשק.** המנוע לא יודע שקיים ממשק. הממשק לא מייבא PyTorch.
2. **המנוע רץ בתהליך (process) נפרד.** קריסה, נעילה או OOM במנוע לא הורגים את החלון.
   ביטול משימה = הרג התהליך. פשוט ובטוח.
3. **כל שלב במנוע הוא צעד עצמאי עם cache.** אם שלב 6 נכשל, שלבים 1–5 לא רצים שוב.
4. **שום מונח טכני לא דולף למשתמש.** כל הודעה בממשק עוברת שכבת "תרגום לעברית פשוטה".
5. **הכול מקומי.** אין שליחת שמע לשום שרת. יציאה לרשת רק להורדת מודלים.

## 4. מודל המשימה (Job)

משימה = גרף של צעדים. כל צעד:

```
Step:
  id            "separate_main"
  inputs        [hash של קבצי הקלט + כל הפרמטרים]
  cache_key     sha256(inputs)          ← אם קיים ב-cache, מדלגים
  outputs       [נתיבי קבצים]
  vram_hint     כמה זיכרון GPU צפוי
  cancellable   True
  progress      0.0 – 1.0
```

**התאוששות מתקלה:** מצב המשימה נשמר ל-JSON אחרי כל צעד. אם התוכנה נסגרה באמצע —
בפתיחה הבאה מוצג "מצאנו עבודה שלא הסתיימה. להמשיך?" והיא ממשיכה מהצעד הבא.

**ביטול:** דגל ביטול נבדק בין צעדים ובתוך לולאות ארוכות. אם לא נענה תוך 3 שניות —
התהליך נהרג בכוח והקבצים הזמניים מנוקים.

**טיפול ב-OOM:** מנהל VRAM מרכזי. כשנתפסת שגיאת OOM:
`chunk ÷ 2` → נסה שוב → `batch = 1` → נסה שוב → `overlap` מינימלי → נסה שוב → CPU.
בכל שלב הודעה למשתמש: *"מתאימים את ההגדרות לכרטיס המסך… (ניסיון 2 מתוך 4)"*.


`voice.json`:
```json
{
  "id": "…",

  "consent_confirmed": true,
```

```json
{
  "f0_midi": { "p05": 45.2, "p25": 50.1, "p50": 54.8, "p75": 59.3, "p95": 64.7 },
```

## 6. מנהל המודלים וההורדות

**רישום מודלים (`models.json`)** — נשמר בריפו, מתעדכן עם האפליקציה:
```json
{
  "id": "sep_bs_roformer_leap",
  "kind": "separation",
  "display_name_he": "הפרדה — איכות גבוהה",
  "size_mb": 630,
  "sha256": "…",
  "urls": ["<המראה שלנו>", "<המקור המקורי>"],
  "requires": []
}
```

**Download Manager:**
- הורדה מקבילה עם HTTP Range → **Pause/Resume אמיתי**
- אימות SHA-256 בסיום; קובץ פגום נמחק ומורד שוב
- Retry עם השהיה גוברת (3 ניסיונות), ואז מעבר למראה חלופית
- הודעת שגיאה בעברית פשוטה: *"ההורדה נכשלה. בדוק את חיבור האינטרנט ונסה שוב."* + כפתור "נסה שוב"

**חובה (סיכון #1 במחקר):** נשקף את כל המודלים לריפו HuggingFace פרטי משלנו.
מודלים בקהילה נעלמים — ראינו שרק ~40% מהקטלוג של audio-separator עדיין חי.

## 7. תכנון ה-UX

### 7.1 המסע במצב פשוט

```
①  שיר      →  ②  קול      →  ③  ניתוח     →  ④  האזנה   →  ⑤  תוצאה
   גרירה         כרטיסיות       אוטומטי         Preview      נגן + ייצוא
   לתוך          קולות +        + המלצה         + אישור
   החלון         חיפוש          בעברית
```

**מסך 1 — השיר**
אזור גרירה גדול במרכז: *"גרור לכאן שיר"*. מתחת: כפתור "בחר קובץ" ורשימת שירים אחרונים.
אחרי טעינה: שם השיר, אורך, וצורת גל.

**מסך 2 — הקול**
רשת של כרטיסי קול: תמונה, שם, תיאור בעברית ("קול גברי, טווח בינוני"), כפתור ▶ להשמעה.
כרטיס אחרון: **+ הוסף קול חדש**.

**מסך 3 — רמת איכות (בחירה אחת)**
שלושה כפתורים גדולים: **מהיר** / **מאוזן (מומלץ)** / **איכות מרבית**.
לכל אחד: הערכת זמן. זהו — לוחצים **התחל**.

**מסך 4 — עיבוד**
פס התקדמות אחד גדול + משפט אחד שמשתנה:
- *"מפרידים את השירה מהמוזיקה…"*
- *"מנתחים את גובה הקול…"*
- *"ממירים את הקול…"*
- *"מחברים הכול יחד…"*

**אף פעם לא:** לוגים, אחוזי VRAM, שמות מודלים, פקודות.
בפינה: קישור זעיר "פרטים טכניים" שפותח את הלוג — למי שרוצה.

**מסך 5 — ההמלצה (מופיע אחרי הניתוח)**
כרטיס בהיר עם ההסבר, לדוגמה:

> 🎵 **בדקנו את השיר ואת הקול שבחרת**
> השיר גבוה יחסית לקול "יוסי".
>
> **✅ מומלץ:** להוריד את השירה באוקטבה שלמה.
> המוזיקה נשארת בדיוק כמו שהיא.
>
> [ אישור ]   [ אפשרויות אחרות ▾ ]

**מסך 6 — Preview**
נגן עם שני כפתורים: **מקור** / **התוצאה**, מעבר חלק ביניהם באותה נקודת זמן.
מתחת: *"נשמע טוב? [ המשך לשיר המלא ]  [ שנה משהו ]"*

**מסך 7 — התוצאה**
נגן מלא, כפתור **שמור**, כפתור **פתח תיקייה**, כפתור **התחל שיר חדש**.

### 7.2 מצב מתקדם

מתג "מתקדם" בפינה. פותח פאנל צדדי (לא מסך חדש — כדי לא לשבור את הזרימה) עם קבוצות מקופלות:

| קבוצה | מה בפנים |
|-------|----------|
| הפרדה | מודל, Ensemble, DeReverb, ווקאלים מלווים, overlap |
| גובה | חצאי טונים ידני, הזזת פלייבק, formant, ריכוך קפיצות |
| המרת קול | מודל, index_rate, protect, rms_mix, שיטת F0 |
| מיקס | ווליום ווקאל/פלייבק, LUFS יעד, לימיטר, כמות הדהוד |
| מערכת | GPU, גודל chunk, מספר תהליכים, תיקיית פלט |

**כל שדה מלווה ב-ⓘ שמסביר במשפט אחד בעברית.**
כפתור "החזר לברירות מחדל" תמיד זמין.

### 7.3 עיצוב

- **RTL מלא** דרך `QGuiApplication.setLayoutDirection(Qt.RightToLeft)`.
- פונט: **Rubik** או **Assistant** (Google Fonts, רישיון OFL, נארוז אותם).
- מצב כהה כברירת מחדל + מצב בהיר.
- טקסט מעורב עברית/מספרים/אנגלית — עטיפה בתווי bidi מפורשים כדי למנוע קפיצות.
- אנימציות עדינות בלבד (150–250ms), בלי "ריקודים".

## 8. תרגום שגיאות לעברית

טבלת מיפוי מרכזית — לכל שגיאה של המנוע יש הודעה אנושית + פעולה מוצעת:

| קוד | מה המשתמש רואה |
|-----|-----------------|
| `E_GPU_OOM` | "לכרטיס המסך נגמר הזיכרון. ניסינו להתאים את ההגדרות אוטומטית." |
| `E_MODEL_MISSING` | "חסר קובץ. נוריד אותו עכשיו — זה ייקח כדקה." |
| `E_AUDIO_UNSUPPORTED` | "לא הצלחנו לפתוח את הקובץ. נסה MP3, WAV או M4A." |
| `E_VOICE_CORRUPT` | "קובץ הקול פגום. אפשר להסיר אותו ולהוסיף מחדש." |
| `E_DISK_FULL` | "אין מספיק מקום בדיסק. צריך עוד 4GB פנויים." |
| `E_NO_VOCALS` | "לא זיהינו שירה בקובץ. אולי זה שיר אינסטרומנטלי?" |

**כלל:** כל שגיאה חייבת לכלול (1) מה קרה, (2) מה לעשות. אף פעם לא stack trace.

## 9. תוכנית Git

**ריפו:** פרטי, ב-GitHub.

**ענפים:**
- `main` — תמיד עובד. כל שלב שהושלם מתמזג לכאן.
- `phase/N-שם` — ענף עבודה לכל שלב. נמחק אחרי מיזוג.

**קומיטים:** [Conventional Commits](https://www.conventionalcommits.org) —
`feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `build:`.

**גרסאות:** SemVer. תגית בסוף כל שלב: `v0.1.0` (Phase 1), `v0.2.0` (Phase 2)…
`v1.0.0` = השחרור הראשון המלא.

**CI (GitHub Actions), על Windows runner:**
1. `ruff` (בדיקת סגנון) + `mypy` (בדיקת טיפוסים)
2. `pytest tests/unit` — מהיר, בלי GPU
3. בדיקת הגבול: `svc_app` לא מייבא torch, `svc_engine` לא מייבא PySide6
4. בניית ה-installer — רק על תגיות

**מה נשאר ידני אצלך:** רק לאשר merge ולהריץ פקודה כשאני נותן לך אותה במפורש.

## 10. פרטיות

- ברירת מחדל: **הכול מקומי.** אין טלמטריה, אין שליחת שמע, אין חשבון.
- היציאה היחידה לאינטרנט: הורדת מודלים ובדיקת עדכונים — שתיהן ניתנות לכיבוי.
- הלוגים לא מכילים תוכן שמע, רק שמות קבצים ומדדים.
- מסך "פרטיות" בהגדרות שמסביר בדיוק את זה בעברית.
