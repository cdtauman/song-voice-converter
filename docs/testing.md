# תוכנית בדיקות ומערכת השוואת איכות

**העיקרון:** לא בוחרים לפי תחושה. לכל החלטת איכות יש מספר שאפשר להשוות,
**ובנוסף** האזנת A/B — כי בסוף האוזן מכריעה.

---

## 1. סט הבדיקה

נצטרך **5 שירים** שיש לך הרשאה להשתמש בהם, שמכסים מקרים שונים:

| # | סוג | למה זה חשוב |
|---|-----|--------------|
| 1 | פופ נשי, ווקאל נקי, בלי ווקאלים מלווים | המקרה הבסיסי |
| 2 | שיר עם ווקאלים מלווים ומקהלה | בודק את שלב הפרדת הליווי |
| 3 | שיר עם הרבה הדהוד (בלדה, אולם) | בודק DeReverb והחזרת ההדהוד |
| 4 | שיר עם טווח רחב במיוחד (מנמוך לגבוה) | בודק את מנוע המנעד |
| 5 | הקלטה באיכות ירודה / חיה | בודק עמידות |

בנוסף: **2 קטעים "יבשים"** — ווקאל מבודד מקורי (בלי מוזיקה) שיש לך.
אלה משמשים כ"אמת מוחלטת" למדידת איכות ההפרדה: נערבב אותם עם פלייבק ידוע,
נריץ הפרדה, ונמדוד כמה קרוב הפלט למקור. זו המדידה האובייקטיבית היחידה שאפשרית בלי דאטהסט מסחרי.

> **פעולה נדרשת ממך:** לאסוף את 5 השירים + 2 הקטעים היבשים לתיקייה אחת.
> נעשה את זה לפני Phase 2. הקבצים **לא** ייכנסו לריפו (יש `.gitignore` מתאים).

## 2. רמות הבדיקה

### 2.1 בדיקות יחידה (Unit) — מהירות, בכל commit

בודקות היגיון טהור, בלי GPU ובלי שמע אמיתי:
- מתמטיקת המנעד: `s = 12k + r`, פונקציית העלות, בחירת המועמד
- המרות MIDI ↔ הרץ ↔ שם תו
- חישוב `cache_key` — האם שינוי פרמטר באמת משנה את המפתח
- אימות checksum, לוגיקת retry
- פירוק והרכבת מניפסט קול
- תרגום שגיאות — כל קוד שגיאה חייב הודעה בעברית

**יעד:** מעל 80% כיסוי במודולי הלוגיקה. רצות בפחות מ-30 שניות.

### 2.2 בדיקות DSP עם קובץ ייחוס (Golden)

לוקחים קטע קצר (5 שניות), מריצים עליו פעולה, ומשווים לתוצאה שאושרה בעבר —
עם סובלנות מספרית (לא השוואה מדויקת, כי GPU לא דטרמיניסטי לחלוטין).

בודקים כך: resample, נרמול LUFS, הזזת גובה, סכימת מיקס, לימיטר.

### 2.3 בדיקות אינטגרציה — לילי / לפני מיזוג

מריצות את הצינור המלא על קטעים של 30 שניות מסט הבדיקה.
בודקות: אין קריסה, האורכים נכונים, ה-LUFS ביעד, אין clipping, אין NaN.

### 2.4 בדיקות עמידות

| תרחיש | התוצאה הצפויה |
|-------|----------------|
| קובץ שמע פגום | הודעה בעברית, בלי קריסה |
| שיר אינסטרומנטלי (בלי שירה) | "לא זיהינו שירה" |
| שיר של 10 דקות | מסתיים בהצלחה |
| ניתוק אינטרנט באמצע הורדת מודל | Resume עובד אחרי חיבור מחדש |
| דיסק מלא | הודעה ברורה, ניקוי, בלי אובדן מידע |
| הריגת התהליך באמצע כל שלב | התאוששות בהפעלה הבאה |
| כפיית OOM (chunk ענק) | סולם הנסיגה מתגבר על זה |
| נתיב עם עברית ורווחים | עובד (או נכשל בהודעה ברורה) |

## 3. המדדים — איך מודדים "איכות" במספרים

### 3.1 להפרדה

| מדד | מה הוא אומר | דורש ווקאל יבש? |
|-----|--------------|------------------|
| **SDR** | כמה נקי ההפרדה, ב-dB. גבוה = טוב | כן |
| **דליפת כלים** | כמה אנרגיה של הפלייבק נשארה בווקאל | כן |
| **מלאות** (Fullness) | כמה מהווקאל המקורי שרד (לא "נחתך") | כן |
| **זמן עיבוד** | שניות | לא |
| **שיא VRAM** | MB | לא |

### 3.2 להמרת קול

| מדד | מה הוא אומר | איך מודדים |
|-----|--------------|------------|
| **שימור מנגינה** | האם התווים נשארו אותם תווים | מתאם בין עקומת ה-F0 של הפלט לזו של המקור (אחרי ההזזה). יעד: מעל 0.97 |
| **שימור מילים** | האם המילים עדיין מובנות | WER — מריצים Whisper על המקור ועל הפלט ומשווים את התמלול. יעד: פער קטן מ-10% |
| **דמיון לקול היעד** | כמה זה נשמע כמו הקול שבחרנו | מרחק קוסינוס בין embedding של הפלט ל-embedding של דגימת היעד. יעד: מעל 0.80 |
| **שימור דינמיקה** | האם החזק נשאר חזק והחלש חלש | מתאם בין מעטפות ה-RMS. יעד: מעל 0.90 |
| **artifacts** | רעשים מלאכותיים | ספירת clicks + בדיקת אנרגיה בתדרים גבוהים חריגים |

> **הערה כנה:** כל המדדים האלה הם *קירובים*. הם מצוינים כדי לפסול אפשרות גרועה
> ולצמצם מ-10 אפשרויות ל-3. הבחירה הסופית בין ה-3 נעשית באוזן.

### 3.3 לביצועים

זמן לכל שלב, שיא VRAM, שיא RAM, מקום בדיסק שנתפס, כשלים.

## 4. מעבדת הבנצ'מרק

תיקיית `benchmark/` תכיל מערכת שמריצה **מטריצת ניסויים** ושומרת הכול.

**קובץ ניסוי (`experiments/sep_models.yaml`):**
```yaml
name: "השוואת מודלי הפרדה"
songs: [song1, song2, song3, song4, song5]
variants:
  - id: melband_kim
    separation: { model: "melband_roformer_kim", overlap: 4 }
  - id: bs_leap
    separation: { model: "bs_roformer_leap", overlap: 4 }
  - id: ensemble2
    separation: { models: ["bs_roformer_leap", "melband_roformer_kim"], mode: "avg" }
metrics: [sdr, bleed, fullness, time, vram]
```

**הרצה:**
```bash
svc-bench run experiments/sep_models.yaml --out results/2026-08-20/
```

**התוצאה:**
- `results.csv` — כל המספרים
- `report.html` — טבלה + גרפים
- `audio/` — כל הפלטים, מסודרים להאזנת A/B
- `manifest.json` — בדיוק אילו גרסאות מודלים והגדרות רצו (שחזוריות מלאה)

**נגן A/B בממשק:** מסך ייעודי שמקבל תיקיית תוצאות ומאפשר מעבר מיידי בין וריאנטים
באותה נקודת זמן, עם אפשרות **מבחן עיוור** (השמות מוסתרים) כדי למנוע הטיה.

## 6. שערי איכות (Quality Gates)

**לא ממזגים ל-`main` אם:**
- בדיקות היחידה נכשלות
- `ruff` או `mypy` צועקים
- בדיקת הגבול נשברה (`svc_app` מייבא torch או להפך)
- שלב חדש הרע מדד קיים ביותר מ-5% בלי הסבר מתועד

**לא משחררים גרסה אם:**
- יש באג חוסם ידוע
- בדיקות העמידות לא עברו
- ההתקנה על מכונה נקייה נכשלה
- יש הודעת שגיאה שאינה בעברית או שאין בה מה לעשות
