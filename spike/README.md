# Compatibility Spike — Phase 1

## מה זה עושה

עונה על שאלה אחת:

> האם קיימת מטריצת תלויות אחת, על מחשב היעד, שמריצה **יחד ובאופן אמין**
> הפרדת RoFormer + זיהוי גובה + המרת קול + הזזת גובה?

הרכיבים האלה נכתבו ע"י אנשים שונים בשנים שונות. קונפליקטי תלויות הם התקלה
מספר אחת בפרויקטים כאלה, ואסור לגלות אותם ב-Phase 5.

## איך מריצים

```bash
python spike/run_spike.py
```

הסקריפט מזהה לבד אם יש כרטיס NVIDIA. אם אין — הוא **מדלג** על מועמדי ה-CUDA
ומסמן אותם בבירור כ"חייבים לרוץ על מחשב היעד", במקום לדווח על הצלחה מדומה.

אפשרויות:

| דגל | מה הוא עושה |
|-----|--------------|
| `--only cpu-311` | להריץ מועמד אחד בלבד |
| `--keep-venvs` | לא למחוק את סביבות הניסוי בסוף |
| `--force-gpu` | להריץ מועמדי CUDA גם בלי זיהוי דרייבר |

## מה נבדק בכל מועמד

`spike/smoke_test.py` רץ **בתוך** כל סביבה ובודק, לכל רכיב, שהוא באמת עובד —
לא רק שהוא מותקן:

| בדיקה | מה היא מוודאת |
|-------|----------------|
| `torch` | גרסה, זמינות CUDA, ושכפול מטריצות אמיתי על המכשיר |
| `numpy` / `scipy` | נטענים |
| `soundfile` | כתיבה וקריאה של WAV הלוך ושוב |
| `librosa` | ניתוח אמיתי (YIN על צליל ידוע) |
| `pyloudnorm` | מדידת LUFS על אות ידוע |
| `pitch_shift` | **הזזת גובה של אוקטבה ואימות שהאורך נשמר בדיוק** |
| `audio_separator` | ייבוא ונוכחות ה-API (הורדת מודלים היא Phase 2) |
| `torchfcpe` | נטען |
| `ffmpeg` | קיים, ויש בו `loudnorm`, `alimiter`, `acompressor`, `aresample` |

## התוצרים

| קובץ | מה יש בו |
|------|----------|
| `spike/results/<timestamp>/results.json` | הנתונים הגולמיים |
| `docs/compat-matrix.md` | טבלה קריאה — מה עבר, מה נפל, ולמה |
| `constraints.txt` | **מטריצת התלויות הנעולה**, נכתב רק אם מועמד עבר במלואו |

## מועמדים

| מזהה | תיאור | דורש NVIDIA |
|------|-------|--------------|
| `cpu-311` | Python 3.11 + torch CPU | לא |
| `cpu-312` | Python 3.12 + torch CPU | לא |
| `cu128-311` | Python 3.11 + torch CUDA 12.8 | כן |
| `cu126-311` | Python 3.11 + torch CUDA 12.6 | כן |
| `cu128-312` | Python 3.12 + torch CUDA 12.8 | כן |

## אם שום מועמד לא עובר

זו לא קטסטרופה — זו **תוכנית ב'** שהוגדרה מראש ב-`docs/architecture.md`:
שתי סביבות Python נפרדות (`env-sep` להפרדה, `env-vc` להמרה) שמתקשרות דרך קבצים.
פחות אלגנטי, אבל מסיר את הסיכון לחלוטין.
